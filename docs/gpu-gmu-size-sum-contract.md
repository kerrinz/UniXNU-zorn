# GMU size-preflight sum overflow

After closing the Service callback SIZE_MAX investigation without a reachable witness,the same round moved to a distinct pure size-validation path. The exact GMU allocator's public contract requires every supplied size to fit its existing fixed range. Its preallocation predicate added dummy+log+hfi in uint64_t before comparison. Three page-aligned tuples containing UINT64_MAX-4095 plus two4096-byte sizes wrap the sum to4096 and pass that predicate despite exceeding the shared span. The earlier nonzero/alignment/SIZE_MAX checks accept these tuples on arm64. The checked-in default-size caller is not claimed to hit this case.

An independent UNAPPLIED candidate checks the remaining shared span with short-circuited subtraction before any native allocation. Each subtraction is protected by its preceding bound. The complete original source is otherwise byte-identical. The fixed-source layout constants are used solely to check the existing scalar input contract;they are not selected K80 geometry or supplied mappings. No policy value, address accessor, allocator retry, mapping, cleanup, public type or output field was added.

Only extracted size-predicate code ran on the host. Three overflow witnesses now refuse and exact-span/one-page-over/below controls retain their results under ASan/UBSan. No NativeAdrenoMemory or allocator object was constructed and allocate/getters/providers were never called. One changed-candidate iOS17 module object compiled with the existing real-header recipe;it was not linked or executed. Original catalog, old mapping-retention candidate,32 patches and8 profiles remain unchanged and uncombined.

The callback-offset review is source-only,not a new test or hardware milestone. A separate pending source question is NativeAdrenoHandleIndex::reserve(keys),whose keys*2 comparison may wrap before capacity/grow checks. Read its existing callers/contracts before deciding whether that is an actual unhandled input gap;do not instantiate a native index/provider or rerun old suites.
