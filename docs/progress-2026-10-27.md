## 当前自然停止位置

用户态通过 `sysctl` 查询 `security.mac.img4.ignition_blob`：

```text
MIB: 101.101.118.100
SCTBEGIN
security.mac.img4.ignition_blob
SCTEND
SCH04A948EC
SCP00000000 SCMAC
SCP00000001 SCMACD
SCP00000002 SCCALL
```

这证明该查询通过了 MAC 检查，并进入原版 AppleImage4 处理函数
`0xfffffff004a948ec`；本轮没有观察到处理函数返回（`SCRET`）。
时间约为 UFS 日志就绪后 250 毫秒，随后独立 watchdog 自动复位至 recovery。
第 64 次 SVC 检查点未命中；第 32 次检查点在较早的独立试验中已主动命中。

当前 AppleImage4 可执行段与原始 IPSW 逐字节一致，SHA256 为
`94eee9bff8da89bb6cd12c5c8ba0c3e2ec186783f26a2e14a8c8dba0046c1290`。
静态审计在该处理函数前 192 字节中解析到 `_lck_mtx_gate_wait`，
但尚未采到处理函数内部的运行时栈，不能确定最后停在该等待门的哪条指令。
见 [审计结果](evidence/image4-handler-audit.json) 和
[真机日志](evidence/ignition-sysctl.txt)。

## 本轮完成的实质进展

1. 恢复并验证无人值守链路：recovery → bootloader → 定向 `fastboot boot` →
   检查点或独立超时复位 → recovery ADB → 自动读回日志。
2. 通过原厂内核与运行中设备树确认 Gunyah watchdog ABI。主动屏蔽中断并停 CPU 的
   独立超时试验也能自动进入 recovery；普通调试使用 55 秒 bite。
3. 提取未修改的 j120ap Static/System trust cache，校验 BuildManifest 摘要，
   补上官方 runtime 配置和 ADT 占位。`TC00000003`、`SIGPASS`、`INITOK` 已通过。
4. 参照 sheng 的精确原版 PMGR ABI：对象生命周期、原版 nub/provider 绑定、
   AON 常量读/空写、服务发布及实际查找均成功。此项不代表完整 SoC 电源管理。
   后续 AMFI 实际消费此服务的完整路径仍待验证。
5. 将用户拷贝故障缩小到 `_bcopyin+0x34` 的重复 L3 读权限异常。
   补选官方 ARM64 的 `CONFIG_XNU_NATIVE_PAN=y`，重新编译后正常命中 `MACIN`；
   Mach VM 分配完整返回 0。观测调用已移出 PAN 临时关闭窗口。
6. 真机验证 EL0、`mprotect=0`、`getpid=1` 和第 32 次 SVC。
   用户文本实际写入 fd 3，已采到 `Darwin Ignition Sequence Version 1.0.0`
   以及 `libignition-56~62436/RELEASE_ARM64` 的启动参数输出。
7. 持久日志升级为 ZORNLOG2：340 个 12 字节循环槽，保存完整 panic、
   用户 write 片段、单调毫秒时间、sysctl MIB、解析名称和处理边界。
8. 主机增加遇错即停的构建/打包流程，记录构建状态与哈希；启动前核对镜像身份。
   失败构建的旧镜像反向控制已验证为零 USB 命令。

PMGR 发布与用户拷贝都是独立验证的里程碑。早先屏幕最后的 `CSMAC`、`MPAD`
不能单独作为当前主线程自然停止位置；原始日志及时间记录能区分后台活动。

## 当前存储布局

`userdata` 中已有 9382658048 字节的 SHNGROOT 镜像，包含原始 OS 与 SystemOS
窗口。当前实现只发布 OS APFS 容器为只读 `md0`；SystemOS 单独发布/挂载、
完整卷身份验证、启动清单以及可写 Data 还没有在 zorn 上接通。

恢复内存盘仍随负载携带，展开约 176 MiB，但它不是当前根卷。XNU 当前
`owned_memory_size=0x18000000`（384 MiB）。尚未移除这份恢复盘或扩大内存配置。

OS 回调不写盘。诊断只使用 userdata 既有 4 KiB 日志块与 misc recovery BCB 页。
本轮未再刷 userdata，也没有刷 boot/super/vbmeta/vendor_boot 或切换槽位。
Android userdata 先前已获授权改用于 iPadOS；当前不能启动 Android 或声称双系统共存。
